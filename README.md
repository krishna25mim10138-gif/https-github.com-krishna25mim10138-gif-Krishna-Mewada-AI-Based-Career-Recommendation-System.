
AI Based Career Recommendation System

About

AI system that recommends careers based on student skills and performance.

Features

Predicts careers using Decision Tree Classifier.
Supports CLI and Streamlit web interface.
Includes sample dataset with math, coding, communication scores.
Lightweight and beginner friendly project.
Customizable dataset for real world testing.
Interactive UI for easy usage.
Educational project for ML beginners.


Requirements

Python 3.x installed.
VS Code, Jupyter Notebook, or any IDE.
Libraries: pandas, scikit-learn, tkinter, streamlit.



Usage


Run CLI mode with python main.py.
Run Streamlit mode with streamlit run app.py.
Enter scores and get career recommendation instantly.

Project Structure


app.py → Streamlit UI.
main.py → CLI execution.
model.py → CareerModel class.
dataset.csv → Sample dataset.
requirements.txt → Dependencies.
README.md → Documentation.



Dataset


Contains scores in math, coding, communication.
Maps careers like Software Engineer, Data Scientist, HR Manager, UI/UX Designer.
Supports CSV format for easy customization.



Future Scope


Add aptitude, interests, personality traits.
Use advanced ML models like Random Forest or Neural Networks.
Deploy on cloud platforms for global access.
Build counselor dashboard for student data.
Add career probability visualization.
Integrate database for record storage.
Provide career guidance with resources and learning paths.



Learning Outcomes


Learn how to build ML models in Python.
Practice Decision Tree Classifier for classification.
Work with datasets using pandas.
Build interactive apps using Streamlit.
Structure Python projects with multiple files.
Understand basics of career guidance systems.
