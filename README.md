AI Based Career Recommendation System

About
This project is used to recommend suitable career options to students based on their skills, interests and other inputs.
The system takes user information and uses a machine learning model to give career recommendations.

Requirements
Python 3.x
VS Code or any Python IDE
Required Python libraries

Setup
1. Download the Project
   Download or clone this repository and open the project folder.

2. Create Virtual Environment
   Open the terminal in the project folder and run:
   python -m venv venv
   For Windows:
   venv\Scripts\activate

3. Install Libraries
   Run:
   pip install -r requirements.txt

Configuration
Make sure the dataset and model files are present in their required folders.
If any file path is changed, update the path in the Python code.

Run
Run the application using:
   streamlit run app.py
The application will open in the browser.
Enter the required details and submit them to get the career recommendation.
